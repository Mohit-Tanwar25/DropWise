> ⚡ **Built in just 3 hours!** 
> 
> **DropWise** is a responsive web application dedicated to promoting water conservation, sustainable habits, and raising awareness about global water challenges. Built rapidly in a 3-hour sprint, it features a complete daily water usage tracker, actionable conservation tips, and project showcases to help you make every drop count.

---

## 📌 Features

- 📊 **Interactive Water Usage Tracker**: Log your daily consumption (showers, dishes, laundry, toilet flushes, lawn watering) with live calculation of gallons used, weekly averages, and gallons saved.
- 💡 **Conservation Tips & Guides**: Practical tips and strategies for saving water at home, school, and work.
- 🖼️ **Gallery & Projects**: Inspiring photo showcase of rainwater harvesting, rooftop gardening, and sustainable community water projects.
- 📈 **Impact & Statistics**: Real-time awareness facts and data highlighting the global water crisis.
- 📬 **Contact & Feedback**: Easy-to-use contact form to connect with the community and share suggestions.
- 📱 **Fully Responsive**: Optimized for desktops, tablets, and mobile devices with interactive navigation.

## 🚀 Getting Started

No build tools or heavy installations required! Run DropWise locally in seconds:

### Option 1: Direct Browser Launch
Simply double-click `index.html` or run:
```powershell
start index.html
```

### Option 2: Local HTTP Server (Recommended)

#### Using Python:
```powershell
python -m http.server 8000
```
Open **[http://localhost:8000](http://localhost:8000)** in your web browser.

#### Using Node.js / npx:
```powershell
npx serve .
# or
npx live-server
```
